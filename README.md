# דף ריק

דף משותף: כל דפדפן מקבל ריבוע אחד ליום, מצייר וכותב בו, מזיז ומסובב אותו. בחצות (שעון ישראל) הכול מתרוקן.
מצב "רשת" מציג כל ריבוע כעיגול שגודלו לפי מספר הצופים.

- `index.html` – כל הדף
- `api/` – פונקציות Vercel (events, claim, act, view, views, admin)
- אחסון: Upstash Redis (דרך Vercel Marketplace). מפתחות של כל יום פגים אחרי 48 שעות.
- מנהל: פותחים `/admin`. כניסה בסיסמה (`ADMIN_PASSWORD` ב-Vercel, לפחות 8 תווים) או עם Google (`GOOGLE_CLIENT_ID` + `ADMIN_EMAIL`). הסיסמה והמייל נשמרים רק שם, לא בקוד.
- פיתוח מקומי: `npm run dev` (אחסון בזיכרון).
